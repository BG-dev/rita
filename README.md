# Movie Sync

Совместный просмотр Rutube и VK Video через официальные embed-плееры.
Состояние комнаты живёт на сервере как «якорь» (позиция + момент времени),
клиенты проецируют его на текущее серверное время.

## Запуск

    npm install
    npm run dev

Откройте http://localhost:5173

## Провайдеры

VK — официальный JS API (`https://vk.ru/js/api/videoplayer.js`), методы
play / pause / seek / getCurrentTime и события inited / timeupdate / paused.
См. client/src/lib/vkAdapter.ts.

Rutube — postMessage. Имена сообщений в shared/protocol.ts помечены как
непроверенные: откройте комнату с ?debug=1, нажмите play внутри плеера и
сверьте содержимое консоли. Правится только таблица, адаптер не трогается.

## Что важно помнить

- js_api=1 должен быть в src с первого рендера, иначе VK API не включится.
- Позиция у VK приходит целыми секундами — precision() автоопределяется,
  при целых порог коррекции 2 с, при дробных 0.5 с.
- Реклама (adStarted..adCompleted) полностью отключает синхронизацию:
  во время ролика плеер сообщает время рекламы, а не видео.
- autoplay=1 намеренно не ставится: первый play должен быть по клику.
